# Handoff: sttak — 주식 초보자 투자 학습 앱 (iOS)

> 이 문서 하나만으로 디자인 의도와 모든 화면을 처음부터 구현할 수 있도록 작성했습니다.
> 대화 과정에서 내린 세심한 디자인 판단까지 모두 담았습니다.

---

## Overview

**sttak**은 주식을 처음 시작하는 초보 투자자를 위한 **투자 학습 앱**입니다.
"감"이 아니라 **데이터와 이유**로 투자 결정을 내리고 싶지만 차트·용어가 낯선 사람이 타깃입니다.

앱이 해결하는 문제:
1. 관심종목 **뉴스/공시를 호재·중립·악재로 정리**하고, 어려운 내용을 **쉬운 한국어로 풀어** 줍니다.
2. **모의투자**와 **차트 학습**으로 안전하게 투자를 연습하게 합니다.
3. **퀴즈·랭킹**으로 학습 동기를 자연스럽게 부여합니다.

이 번들에는 다음 사용자 플로우가 화면으로 구현돼 있습니다:

```
스플래시 → 로그인(카카오/구글) ─┬─ 신규 유저 → 관심종목 온보딩 → 홈
                                └─ 기존 유저 ──────────────────→ 홈

홈 (탭바: 홈 · 차트학습 · 퀴즈 · 마이)
 ├ 뉴스 카드 탭 → 뉴스 상세 시트 (쉬운풀이 / 원문 / AI에게 묻기)
 ├ 차트학습 → 캔들차트·지표 학습·과거 신호 → 모의 매수/매도 → AI 회고 → 한 달 후 후속 회고
 ├ 퀴즈 → 6시간마다 3문제 → 정답 시 모의 자본금 적립 → 랭킹
 └ 마이 → 보유 자산·관심종목·매매기록·AI 회고기록·랭킹·계정
```

## About the Design Files

`design_files/` 안의 파일들은 **HTML로 만든 디자인 레퍼런스**입니다 — 최종 룩앤필과 동작을 보여주는 **프로토타입**이며, 그대로 복사해 출시하는 프로덕션 코드가 아닙니다.

구현 작업은 이 HTML 디자인을 **타깃 코드베이스의 기존 환경(React Native, SwiftUI, Flutter 등)으로 재현**하는 것입니다. 기존 환경이 있다면 그 패턴·라이브러리·디자인 시스템을 따르세요. 아직 환경이 없다면, iOS 네이티브 느낌이 핵심이므로 **SwiftUI** 또는 **React Native(+Reanimated)**가 적합합니다.

> `.dc.html` 파일은 "Design Component" 포맷이며 `support.js`라는 런타임으로 브라우저에서 바로 열립니다. 이 런타임은 **레퍼런스를 돌려보기 위한 것일 뿐** 프로덕션과 무관합니다. 로직(상태·핸들러)은 각 파일 하단 `<script>` 안의 `class Component`에 들어 있고, 마크업은 그 위 `<x-dc>` 안에 인라인 스타일로 들어 있습니다. `{{ ... }}`는 템플릿 바인딩입니다.

### 파일 → 화면 매핑

| 파일 | 담긴 화면 |
|---|---|
| `sttak Prototype.dc.html` | 스플래시 · 로그인(분기 토글) · 관심종목 온보딩 · 홈 미리보기 + 우측 **유저 플로우 다이어그램** |
| `sttak Home.dc.html` | **홈 탭(메인)** + 뉴스 상세 시트(쉬운풀이/원문/AI) + 하단 탭바 |
| `sttak 차트학습.dc.html` | 캔들 차트학습 + 지표 6종 + 과거 신호 시각화 + 모의 매수/매도 + AI 회고 + 한 달 후 후속 회고 |
| `sttak 마이.dc.html` | 마이페이지(자산·관심종목·매매기록·회고기록·랭킹·계정) |
| `sttak 퀴즈.dc.html` | 퀴즈 탭(3문제·해설·결과·쿨다운) |
| `sttak 랭킹.dc.html` | 랭킹(자산/포인트 토글·내 순위·상위 랭커) |
| `sttak-data.js` | 종목·뉴스·상세·AI 답변 등 **비즈니스 데이터**(스타일 없음) |

> 참고: `sttak Prototype.dc.html`의 홈은 플로우 시연용 **간단 버전**이고, 실제 홈은 `sttak Home.dc.html`가 정본입니다.

## Fidelity

**High-fidelity (hifi).** 최종 컬러·타이포·여백·인터랙션이 모두 확정된 픽셀 단위 목업입니다. 색상 hex, 폰트 크기/굵기, radius, 그림자 값을 그대로 따라 구현하세요. 단, 코드베이스에 동등한 컴포넌트(버튼·시트·세그먼트 컨트롤 등)가 있으면 그 위에 이 토큰을 입혀 재현하면 됩니다.

## ⭐ 디자인 원칙 — 반드시 지켜야 할 의도

대화에서 세심하게 합의한 방향입니다. 시각 구현보다 이게 더 중요합니다.

1. **따뜻하고 접근성 있는 핀테크.** 토스·케이뱅크의 신뢰감/직관성을 참고하되, 차갑고 딱딱한 "전문가용"이 아니라 **초보자가 편하게 다가오는 따뜻한 톤**. 어두운 배경 대신 **종이톤 베이지(#F7F4EE)**가 베이스. 가볍거나 유치하지 않게, 금융 앱다운 신뢰감은 유지.

2. **여백과 타이포로 완성도를 낸다.** 다음은 **금지**:
   - 과도한 그라데이션, 흔한 보라-파랑 그라데이션 배경
   - 의미 없는 이모지/아이콘 (이 앱은 이모지를 쓰지 않음 — 아이콘은 라인 SVG만)
   - 카드마다 그림자 남발 (그림자는 아주 옅게, elevation 1단계만)
   - 전형적인 생성형 AI 앱처럼 보이는 컴포넌트(좌측 컬러 보더 카드, 둥근 모서리 남발 등)

3. **호재/중립/악재 = 한국 증시 관례색.**
   - 호재(상승) = **빨강**, 악재(하락) = **파랑**, 중립 = **회색**
   - 브랜드 컬러 **틸(#0FA39A)**은 상승/하락에 절대 쓰지 않음 (등락과 혼동 방지). 틸은 브랜드·선택·CTA·학습 강조 전용.

4. **AI는 전면에 내세우지 않는다.** "AI가 분석했습니다"를 강조하지 말 것. 호재/중립/악재 판단과 쉬운 풀이는 **사용자를 자연스럽게 돕는 보조 정보**처럼 보여야 함. 판단은 **단정적이지 않게** ("이 신호가 항상 맞는 건 아니지만, 당시엔 이런 흐름이 있었어요" 식).

5. **모의투자는 "게임 재화"가 아니라 "실제 투자 연습".**
   - 가상 자본은 **원화(원)**로 표기. 포인트 단위(P)나 게임 코인 느낌 금지.
   - 라벨은 **"보유 자산"**, 초기 자본 **10,000,000원(1,000만원)**.
   - 퀴즈 보상(포인트)은 **모의투자 자본금으로 연결**됨을 자연스럽게 보여줌.

6. **홈은 "뉴스 앱"이 아니라 "3초 브리핑".** 단순 카드 나열 금지. 사용자가 화면을 열자마자 "오늘 이 종목에 이런 일이 있었구나"를 **3초 안에** 파악해야 함. 가격/등락률은 **종목명 옆 보조 정보**로 컴팩트하게, 메인 영역은 **뉴스/공시 + 쉬운 풀이**가 채움.

7. **iOS 네이티브 느낌.** 다이나믹 아일랜드, 상태바(9:41), 홈 인디케이터. 폰트는 SF 계열 위계(여기선 한글 Pretendard + 숫자 Space Grotesk로 구현).

## 브랜드 — 로고 / 심볼

대화에서 두 방향(A: Ink&Teal / B: Paper&Emerald)을 제안한 뒤, **A의 구조·완성도를 유지하되 B처럼 따뜻하게 다듬은 최종안**을 채택했습니다.

- **심볼: "리테클(조준경)" 마크.** 정사각 영역의 **네 모서리 ㄱ자 브래킷 + 정중앙 점**. "데이터로 정확히 조준한다"는 의미. 신뢰감(기술적·정밀)과 친근함(둥근 모서리 radius, 따뜻한 배경)을 동시에.
  - 모서리 브래킷: 틸(#0FA39A), 굵기 로고 크기에 비례(78px 로고 → 4px / 26px 로고 → 2.5px), 바깥 모서리만 radius.
  - 중앙 점: 틸 채운 원, 로고 크기의 약 22%.

### 5) 뉴스 상세 시트 — `sttak Home.dc.html`

홈에서 뉴스 탭 시 **하단에서 올라오는 시트**(scSheetUp + 딤). 상단 **세그먼트 3탭**: **쉬운풀이 / 원문 / AI에게 묻기**. 헤더에 종목·호재배지·제목.

- **쉬운풀이 탭** — 사용자가 따라가는 **이해 흐름**으로 구성:
  1. **이 소식, 무슨 뜻인가요?** — 쉬운 한 줄 요약(`easy`) + 100자 내외 풀이(`summary`).
  2. **왜 중요한가요?** — 핵심 포인트 불릿(`why`) + **부드러운 호재/중립/악재 판단**(`reason`, 단정적이지 않게).
  3. **알아두면 좋은 용어** — 용어 풀이 카드(`terms`: 용어+쉬운 정의).
  - "쉽게 보기 / 원문 중심으로 보기" 전환 옵션(세그먼트, nowrap).
- **원문 탭** — 출처·게시 시간 → 본문 미리보기(`lead`, **일부 블러 처리**) → 외부 링크 버튼. 신뢰감 있는 흐름.
- **AI에게 묻기 탭** — AI를 보조처럼:
  - **빠른 선택 질문 3개**(`QUICK`): "이게 왜 중요한가요?" / "주가에 어떤 영향이 있나요?" / "어려운 말 없이 설명해줘".

  - 답변은 **스트리밍 타이핑 UI**(한 글자씩 나타나는 채팅). 자유 질문은 `FREE_ANSWER`로 응답.

- **매수/매도 시트:** 수량 조절, 실시간 가격 기반 금액 계산, 초기 자본 1,000만원에서 차감/증가.

- **랭킹 현황:** 요약 카드 + "전체 보기" → 랭킹 화면. 카드 자체도 탭하면 랭킹으로.

## Interactions & Behavior

- **화면 전환(프로토타입):** 별도 파일 간 이동은 `window.location.href`(파일명). 프로덕션에선 네비게이션 스택/라우터로 대체. 탭바: 홈·차트학습·퀴즈·마이 상호 연결, 마이→랭킹.
- **스플래시:** `splashMs` 타이머 후 로그인. 탭 시 즉시.
- **온보딩 선택:** 토글 방식, 5개 상한(초과 시 토스트), 카운트/CTA 실시간 반영.
- **홈 스와이프:** pointer 드래그로 종목 카드 전환(translateX + opacity + transition). `touch-action: pan-y`로 세로 스크롤과 공존.
- **뉴스 시트:** 하단 슬라이드업 + 딤 백드롭, 세그먼트 3탭 즉시 전환. AI 답변은 setInterval로 한 글자씩 누적(스트리밍 흉내).
- **차트:** canvas 직접 렌더. 줌(휠/핀치) → 보이는 캔들 수 조절, 팬 → offset. 캔들/마커 탭 → 포커스 구간 하이라이트 + 디테일 카드.
- **지표 토글:** 같은 지표 재탭 시 해제. 켜질 때 3개월 프레이밍 + 신호 마커/밴드 draw + progressive 설명.
- **모의 매매:** 근거(빠른선택 or 직접입력 140자) 필수 검증 → 실행 → 포트폴리오/거래기록 저장 → 매도 시 회고 생성.
- **퀴즈:** 선택→확인→해설→다음, 3문제 후 결과, 보상 저장, 6h 쿨다운 카운트다운(setInterval 1s).
- **랭킹:** "N초 전" 타임스탬프 1초마다 갱신, 펄스 점 무한 애니메이션, 모드 토글로 자산/포인트 리스트·내 지표 전환.
- **토스트:** 하단 중앙 pill, 1.8~2초 후 사라짐.

## State Management

프로토타입은 화면별 로컬 상태(`class Component`의 `state`) + **localStorage로 화면 간 공유**. 프로덕션에선 앱 전역 스토어(예: Redux/Zustand/Recoil 또는 SwiftUI `@Observable`)와 서버 API로 대체.

**화면 간 공유 키(localStorage) — 데이터 모델의 핵심:**

```
sttak_port            JSON {cash, hold, avg}  — 모의 포트폴리오. cash 초기 10000000(원)
                      매수 시 cash 감소·hold 증가, 매도 시 반대. 퀴즈 정답 시 cash += 500000
sttak_trades          JSON []  — 매수/매도 기록 [{type:'매수'|'매도', code, qty, price, reason, ts, retro?}]
                      각 매도 항목엔 AI 회고(retro)와 한 달 후 후속 회고가 연결됨
sttak_points          number   — 누적 포인트(기본 1240). 퀴즈 정답 1개당 +50. 랭킹·등급(리그) 산출
sttak_quiz_last       number(ts) — 마지막 퀴즈 응시 시각. now-last >= 6h 이면 새 세트 가능
sttak_quiz_lastscore  number   — 지난 세트 정답 수
sttak_quiz_lastearned number   — 지난 세트 적립 자본금(원)
sttak_ind_seen        JSON {}  — 차트 지표 설명을 본 적 있는지(progressive disclosure용)
```

**화면별 주요 state:**
- Prototype: `screen('splash'|'login'|'onboarding'|'home')`, `userType('new'|'existing')`, `query`, `selected[]`(코드 배열, max 5), `toast`.
- Home: 현재 포커스 종목 index, 드래그 px, 시트 open/탭, AI 채팅 메시지·스트리밍 상태, 새로고침 애니메이션.
- 차트학습: period, zoom, panOffset, indicator(선택 지표), 포커스 구간, 설명 펼침, 매매 시트/회고 상태.
- 퀴즈: phase('playing'|'done'|'cooldown'), qIdx, selected, revealed, answers[], now(타이머).
- 랭킹: mode('asset'|'points'), now(타임스탬프 갱신).
- 마이: 각 회고/거래 카드의 open 펼침 상태.

**데이터 소스:** `sttak-data.js` (export: `STOCKS`, `QUICK`, `FREE_ANSWER`). 종목/뉴스/상세(쉬운풀이·why·reason·terms·lead)·AI 빠른답변이 모두 여기 있음. 프로덕션에선 실시간 시세 API + 뉴스/공시 분류 백엔드 + LLM으로 대체. `sttak Prototype.dc.html`은 자체 종목 리스트(50여 개, KOSPI/KOSDAQ)를 내장 — 온보딩 검색용.
