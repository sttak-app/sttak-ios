# sttak-ios

STTAK 서비스의 iOS 애플리케이션 Repository입니다.

## Tech Stack

- Swift
- Xcode
- Swift Package Manager 또는 CocoaPods

## Local Run

1. Xcode로 프로젝트를 엽니다.
2. 필요한 dependency를 설치합니다.
3. iOS Simulator 또는 실제 기기에서 실행합니다.

## Branch Strategy

- main: 운영 배포 기준 브랜치
- develop: 개발 통합 브랜치
- feature/*: 기능 개발 브랜치
- release/*: 배포 준비 브랜치
- hotfix/*: 운영 긴급 수정 브랜치
